# rosteriq

RosterIQ is a full-stack fantasy football analytics platform designed to help users evaluate rosters, analyze trades, and simulate playoff outcomes.

## Planned Features

- Connect to Sleeper fantasy football leagues
- View teams and rosters
- Evaluate team strength
- Analyze trades
- Recommend waiver pickups
- Simulate playoff and championship probabilities

## Tech Stack

- Next.js
- TypeScript
- Python
- FastAPI
- PostgreSQL
- Tailwind CSS
